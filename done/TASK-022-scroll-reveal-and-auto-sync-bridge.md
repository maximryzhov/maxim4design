# TASK-022: Поддержка scroll-анимаций при экстракции и автопередача FIR без ручной вставки

## 1. Описание задачи
1. На страницах со scroll-reveal анимациями (как в `alfagreen-fitosteny.html`) секции ниже первого экрана имеют `opacity < 1` до прокрутки, поэтому при экстракции на `scrollY = 0` они импортируются в Figma полупрозрачными.
2. Сейчас передача FIR JSON из браузера в плагин Figma требует ручного копирования и вставки JSON в окно плагина.

## 2. Связанные разделы документации
- [ARCHITECTURE.md](file:///e:/Projects/Dev/html2design/ARCHITECTURE.md) (Раздел 5: Вариант через Localhost / WebSocket)
- [FIGMA_HANDOFF_GENERIC.md](file:///e:/Projects/Dev/html2design/FIGMA_HANDOFF_GENERIC.md)

## 3. Технические детали и требования к реализации
- **Scroll-анимации:** Добавить опцию перед экстракцией (в Chrome Extension / экстракторе) плавно или пошагово прокрутить страницу для активации `IntersectionObserver`, либо опционально сбрасывать/нормализовать `opacity: 0` у видимых секций.
- **Автоматическая передача FIR без ручной вставки:**
  - Вариант А (локальный HTTP/WS мост): Chrome Extension отправляет FIR на `http://localhost:<port>/fir`, а `src/plugin/ui.html` (с разрешением `localhost` в `manifest.json`) опрашивает мост и запускает импорт автоматически.
  - Вариант Б (умный авто-импорт из буфера): кнопка «Вставить и импортировать» / авточтение буфера при фокусе окна плагина с проверкой формата FIR.

## 4. Критерии приемки (Definition of Done)
- [x] Секции ниже первого экрана на страницах со scroll-анимациями импортируются с полной непрозрачностью.
- [x] Пользователь может передать FIR из браузера в плагин Figma в 1 клик без ручного копирования-вставки JSON.
