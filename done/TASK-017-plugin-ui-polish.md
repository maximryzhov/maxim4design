# TASK-017: UI плагина Figma

## 1. Описание задачи
Модернизировать интерфейс плагина Figma: сделать приятный дизайн в стилистике нативных плагинов Figma, добавить чтение из буфера обмена в один клик, отображение статуса и прогресс-бара импорта, а также реализовать чанковый (порционный) рендеринг для тяжелых страниц во избежание зависания интерфейса Figma.

## 3. Технические детали и требования к реализации
- В интерфейсе `src/plugin/ui.html` (стилизация через CSS Figma Design System):
  - Кнопка «Вставить из буфера» (использует `navigator.clipboard.readText()`).
  - Индикатор состояния: «Анализ дерева...», «Загрузка шрифтов...», «Генерация слоев (45/300)...».
  - Прогресс-бар (progress bar).
  - Настройки импорта:
    - Чекбокс: «Использовать Auto Layout где возможно».
    - Чекбокс: «Импортировать скрытые элементы».
- В коде песочницы (`src/plugin/code.ts`):
  - Пакетный рендеринг больших деревьев:
    - Разбиение рекурсии на чанки по 100 элементов с передачей управления через `setTimeout(..., 0)` для обновления UI.
    - Отправка прогресса в UI: `figma.ui.postMessage({ type: 'PROGRESS', current, total })`.

## 4. Критерии приемки (Definition of Done)
- [x] Окно плагина выглядит чисто и нативно для пользователей Figma.
- [x] При импорте страниц с 1000+ элементов интерфейс Figma не «фризится» намертво, виден живой прогресс-бар.
- [x] По завершении импорта выводится понятное сообщение об успехе или список предупреждений (например, какие шрифты были заменены на fallback).
